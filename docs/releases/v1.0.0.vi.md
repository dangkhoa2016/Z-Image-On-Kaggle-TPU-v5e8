# Z-Image trên Kaggle TPU v5e-8 — v1.0.0

> 🌐 Ngôn ngữ / Language: [English](https://github.com/dangkhoa2016/Z-Image-On-Kaggle-TPU-v5e8/blob/v1.0.0/docs/releases/v1.0.0.md) | **Tiếng Việt**

## Bản public đầu tiên

`v1.0.0` là bản phát hành đầu tiên dành cho cộng đồng của một stack **inference `Tongyi-MAI/Z-Image` đầy đủ, không distilled, trên Kaggle TPU v5e-8**. Release không dừng ở mức “model khởi động được”: production configuration đã được đo với một PJRT process sử dụng đủ tám TPU devices, mesh `(replica=4, model=2)`, BF16 transformer inference, bốn output 1024×1024 đồng thời và evidence có version cho các tuyên bố được công bố bên dưới.

Repository không redistribute Z-Image weights. Prompt encoding và VAE decode nằm phía CPU; transformer denoising chạy trên TPU bằng PyTorch/XLA với manual SPMD parameter sharding.

## v1.0.0 đã chứng minh được gì?

- **Full-model execution:** accepted transformer path không dùng GGUF, quantization hay distillation.
- **Sử dụng đủ tám TPU devices:** 521 transformer parameter tensors được shard trong runtime đã accepted.
- **Production topology:** `(replica=4, model=2)` với global batch 4 tại 1024, tạo bốn ảnh đồng thời.
- **Measured 1024 throughput:** 90.264 giây cho bốn output 1024×1024 (`0.04431 img/s`, amortized 22.566 giây/ảnh).
- **Measured HBM boundary:** global batch 4 là maximum safe tested batch tại 1024; batch 5–8 fail XLA compilation do áp lực HBM.
- **Resolution-aware execution:** batched CFG cho workload thông thường, sequential CFG để giảm peak HBM và full-context query-chunked attention cho very-high-resolution validation.
- **Validated stretch boundary:** 2560×2048 (5.24 MP), dùng sequential CFG, query chunk 4096 và explicit XLA synchronization.
- **Publication evidence có thể review:** prompt/seed cố định, runtime identity, benchmark JSON, acceptance reports, output hashes, ảnh accepted, regression tests và repository audit gates.

## Production configuration

| Thành phần | Giá trị đã xác minh |
|---|---|
| Model | `Tongyi-MAI/Z-Image`, full / undistilled |
| Transformer | 6.15B tham số |
| Accelerator | Kaggle TPU v5e-8 / `v5litepod-8` |
| TPU devices | 8 |
| Runtime | PyTorch/XLA + manual SPMD |
| Precision | BF16 transformer inference |
| Production mesh | `(replica=4, model=2)` |
| 1024 global batch | 4 |
| Frozen benchmark 1024 | 90.264 giây / 4 ảnh |
| Độ phân giải lớn nhất đã xác minh | 2560×2048 |

Một fresh Kaggle TPU execution của cùng workload bốn seed tại 1024 hoàn thành trong **90.099 giây**, với warm transformer-forward median khoảng **1.262 s/step**.

Cold compilation và warm execution được báo cáo riêng vì XLA compilation phụ thuộc mạnh vào tensor shape. Không nên diễn giải các số này như một đường pixels-per-second đơn giản.

## Historical topology evidence

Trước khi freeze production path 4×2, dự án đo matched two-image workload với `(replica=2, model=4)` so với control 1×8 model mesh:

| Độ phân giải | 1×8 model mesh, batch=2 | `(replica=2, model=4)`, batch=2 | Pair speedup |
|---:|---:|---:|---:|
| 512×512 | 126.264 s | 95.001 s | **1.329×** |
| 1024×1024 | 288.645 s | 127.218 s | **2.269×** |

Đây là matched-control evidence lịch sử, không phải production recommendation hiện tại. Một thử nghiệm với các PJRT client trên multi-chip subset độc lập cũng fail trước model load; vì vậy accepted multi-replica path dùng một PJRT process trên toàn bộ tám devices.

## Quick start

1. Dùng Kaggle TPU v5e-8 session.
2. Trong Kaggle notebook, chọn **Add Input → Models**, rồi chọn [mirror Tongyi-MAI/Z-Image](https://www.kaggle.com/models/dangkhoa2016/tongyi-mai-z-image) (variation **PyTorch / default / version 1**). Kiểm tra model đã được mount chỉ đọc với file `model_index.json` tại `/kaggle/input/models/dangkhoa2016/tongyi-mai-z-image/pytorch/default/1`.
3. Load source từ tag `v1.0.0` và cài pinned user-space dependencies nhưng giữ PyTorch/XLA runtime của Kaggle.
4. Chạy BF16 TPU health check và live mesh probe `(replica=4, model=2)`.
5. Chạy 512 smoke path và production workload 1024 global batch 4.
6. Chỉ bật pair-throughput hoặc high-resolution qualification khi thật sự muốn chạy các thí nghiệm dài hơn.

Bắt đầu từ [README tiếng Việt](../../README.vi.md) để xem tổng quan và [Hướng dẫn Kaggle](../KAGGLE.vi.md) để xem chi tiết execution.
