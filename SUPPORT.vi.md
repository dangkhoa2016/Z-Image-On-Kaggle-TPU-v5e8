# Hỗ trợ

> 🌐 Ngôn ngữ / Language: [English](SUPPORT.md) | **Tiếng Việt**

## Trước khi hỏi trợ giúp

Hãy xem README, [Kaggle guide](docs/KAGGLE.vi.md), [Troubleshooting](docs/TROUBLESHOOTING.vi.md), [Limitations](docs/LIMITATIONS.vi.md) và frozen evidence trước.

Với câu hỏi kỹ thuật có thể reproduce, hãy cung cấp:

- loại Kaggle TPU và trạng thái runtime;
- version Python, PyTorch, PyTorch/XLA, Diffusers và Transformers;
- command chính xác;
- resolution, steps, CFG, seed, execution mode và topology;
- log liên quan sau khi đã loại secret;
- failure xảy ra trước model loading, trong XLA compile, trong denoise hay trong VAE decode.

## Hỏi ở đâu

Dùng GitHub Issues cho reproducible bug và feature request. Không dùng public issue cho nội dung security-sensitive; hãy làm theo [SECURITY.vi.md](SECURITY.vi.md).

Dự án không cam kết response time hoặc commercial support. Community report hữu ích nhất khi tối giản, có thể reproduce và có evidence.
