# Support

> 🌐 Language / Ngôn ngữ: **English** | [Tiếng Việt](SUPPORT.vi.md)

## Before asking for help

Check the README, [Kaggle guide](docs/KAGGLE.md), [Troubleshooting](docs/TROUBLESHOOTING.md), [Limitations](docs/LIMITATIONS.md), and frozen evidence first.

For reproducible technical questions, include:

- Kaggle TPU type and runtime state;
- Python, PyTorch, PyTorch/XLA, Diffusers, and Transformers versions;
- exact command;
- resolution, steps, CFG, seed, execution mode, and topology;
- relevant logs with secrets removed;
- whether the failure occurs before model loading, during XLA compile, during denoise, or during VAE decode.

## Where to ask

Use GitHub Issues for reproducible bugs and feature requests. Do not use public issues for security-sensitive material; follow [SECURITY.md](SECURITY.md) instead.

The project does not provide guaranteed response times or commercial support. Community reports are most useful when they are minimal, reproducible, and evidence-backed.
